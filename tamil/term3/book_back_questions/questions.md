### அ. சரியான சொல்லைத் தெரிவு செய்து எழுதுவோமா

1. 'மண்ணிலுள்ள' – இச்சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______
   அ. மண்ணி + லுள்ள
   ஆ. மண்ணில் + உள்ள
   இ. மண் + உள்ள
   ஈ. மண்ணில் + உள்ளே

2. 'நிழற்படம்' – இச்சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______
   அ. நிழள் + படம்
   ஆ. நிழை + படம்
   இ. நிழல் + படம்
   ஈ. நிலை + படம்

3. 'உண்மை' என்ற சொல்லின் பொருள் ______
   அ. பொய்
   ஆ. தவறு
   இ. சரி
   ஈ. மெய்

4. 'நற்பயன்' – இச்சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______
   அ. நல்ல + பயன்
   ஆ. நன்மை + பயன்
   இ. நல் + பயன்
   ஈ. நற் + பயன்

5. 'அருகில்' என்ற சொல்லின் எதிர்ச்சொல் ______
   அ. பக்கத்தில்
   ஆ. எதிரில்
   இ. அண்மையில்
   ஈ. தொலைவில்

## மாசில்லாத உலகம் படைப்போம்

> **மூலச் சான்று (Source Reference):** [HTML Page](file:///e:/19.03.26/new%20project/tn_school_books/4th/tamil/term3/unit_01/page_18/page_18.html)

### அ. சரியான சொல்லைத் தெரிவு செய்து எழுதுவோமா

1. ‘மாசு’ – என்னும் பொருள் தராத சொல் ______
   அ. தூய்மை
   ஆ. தூய்மையின்மை
   இ. அழுக்கு
   ஈ. கசடு

2. ‘மாசு + இல்லாத’ – இச்சொல்லைச் சேர்த்து எழுதக் கிடைப்பது ______
   அ. மாசிலாத
   ஆ. மாசில்லாத
   இ. மாசிஇல்லாத
   ஈ. மாசுஇல்லாத

3. ‘அவ்வுருவம்’ என்ற சொல்லைப் பிரிக்கக் கிடைப்பது ______
   அ. அவ் + வுருவம்
   ஆ. அந்த + உருவம்
   இ. அ + உருவம்
   ஈ. அவ் + உருவம்

4. ‘நெடிதுயர்ந்து’ என்ற சொல்லைப் பிரிக்கக் கிடைப்பது ______
   அ. நெடிது + உயர்ந்து
   ஆ. நெடி + துயர்ந்து
   இ. நெடிது + துயர்ந்து
   ஈ. நெடிது + யர்ந்து

5. ‘குறையாத’ என்ற சொல்லின் எதிர்ச்சொல் ______
   அ. நிறையாத
   ஆ. குறைபாடுடைய
   இ. குற்றமுடைய
   ஈ. முடிக்கப்படாத

### ஆ. வினாக்களுக்கு விடையளிக்க

5. நாம் பயன்படுத்திய மின்பொருள்களை என்ன செய்யவேண்டும்?

### ஈ. எது சரி? எது தவறு? (சரி / தவறு குறியிடுக)

1. கண்ட இடத்தில் குப்பையைக் கொட்டுவது.
2. குப்பையைக் குப்பைத்தொட்டியில் போடுவது.
3. பயன்படுத்தாதபோதும் மின்விளக்கை எரிய விடுவது.
4. நீரைச் சிக்கனமாகப் பயன்படுத்துவது.
5. சாலையின் ஓரமாக நடந்து செல்வது.
6. பறவை, விலங்குகளைத் துன்புறுத்துவது.
