### அ. சரியான சொல்லைத் தெரிவு செய்து எழுதுவோமா

1. ‘மாசு’ – என்னும் பொருள் தராத சொல் ______
   அ. தூய்மை
   ஆ. தூய்மையின்மை
   இ. அழுக்கு
   ஈ. கசடு

2. ‘மாசு + இல்லாத’ – இச்சொல்லைச் சேர்த்து எழுதக் கிடைப்பது ______
   அ. மாசிலாத
   ஆ. மாசில்லாத
   இ. மாசிஇல்லாத
   ஈ. மாசுஇல்லாத

3. ‘அவ்வுருவம்’ என்ற சொல்லைப் பிரிக்கக் கிடைப்பது ______
   அ. அவ் + வுருவம்
   ஆ. அந்த + உருவம்
   இ. அ + உருவம்
   ஈ. அவ் + உருவம்

4. ‘நெடிதுயர்ந்து’ என்ற சொல்லைப் பிரிக்கக் கிடைப்பது ______
   அ. நெடிது + உயர்ந்து
   ஆ. நெடி + துயர்ந்து
   இ. நெடிது + துயர்ந்து
   ஈ. நெடிது + யர்ந்து

5. ‘குறையாத’ என்ற சொல்லின் எதிர்ச்சொல் ______
   அ. நிறையாத
   ஆ. குறைபாடுடைய
   இ. குற்றமுடைய
   ஈ. முடிக்கப்படாத

### ஆ. வினாக்களுக்கு விடையளிக்க

1. ஆசிரியர் வைத்திருந்த அழைப்பிதழில் என்ன செய்தி இருந்தது?
2. அறிவியல் விழாவில் கலந்துகொள்வதற்காக மாணவர்களை ஆசிரியர் எவ்வாறு ஊக்கப்படுத்தினார்?
3. அறிவியல் விழாவில் காணப்பட்ட நெடிதுயர்ந்த உருவத்தை எப்படி உருவாக்கினர்?
4. சுற்றுச்சூழல் சீர்கேட்டுக்கு எவையெல்லாம் காரணமாக அமைகின்றன?
5. நாம் பயன்படுத்திய மின்பொருள்களை என்ன செய்யவேண்டும்?

### ஈ. எது சரி? எது தவறு? (சரி / தவறு குறியிடுக)

1. கண்ட இடத்தில் குப்பையைக் கொட்டுவது.
2. குப்பையைக் குப்பைத்தொட்டியில் போடுவது.
3. பயன்படுத்தாதபோதும் மின்விளக்கை எரிய விடுவது.
4. நீரைச் சிக்கனமாகப் பயன்படுத்துவது.
5. சாலையின் ஓரமாக நடந்து செல்வது.
6. பறவை, விலங்குகளைத் துன்புறுத்துவது.
