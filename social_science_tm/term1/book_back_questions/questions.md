# 4-ஆம் வகுப்பு சமூக அறிவியல் - முதல் பருவம்

## அலகு 1: ஆற்றங்கரை அரசுகள்

---

### பாடநூல் மதிப்பீடு வினாக்கள்

#### அ. சரியான விடையைத் தேர்வு செய்யவும்
1. சேர, சோழ, பாண்டியர்கள் ____________ என அழைக்கப்பட்டனர்.
   - அ) நாயன்மார்கள்
   - ஆ) மூவேந்தர்கள்
   - இ) குறுநில மன்னர்கள்
2. சேரர்களில் புகழ் பெற்ற அரசராகக் கருதப்படுபவர் ____________.
   - அ) கரிகாலன்
   - ஆ) வல்வில் ஓரி
   - இ) சேரன் செங்குட்டுவன்
3. சோழர்களின் துறைமுகம் ____________.
   - அ) காவிரிப்பூம்பட்டினம்
   - ஆ) சென்னை
   - இ) தொண்டி
4. பாண்டியர்களின் கொடியில் இடம்பெற்றுள்ள சின்னம் ____________ ஆகும்.
   - அ) மயில்
   - ஆ) மீன்
   - இ) புலி
5. முல்லைக்குத் தேர் கொடுத்த வள்ளல் ____________ ஆவார்.
   - அ) பாரி
   - ஆ) பேகன்
   - இ) அதியமான்

---

#### ஆ. பொருத்துக
1. சேரர்கள் - வைகை
2. சோழர்கள் - பாலாறு
3. பாண்டியர்கள் - பொய்கை
4. பல்லவர்கள் - காவிரி

---

#### இ. குறுகிய விடையளி
1. சேரர்களில் புகழ் பெற்ற அரசர்கள் யாவர்?
2. ‘கடையேழு வள்ளல்கள்’ என்போர் யாவர்?
3. கரிகாலனின் சாதனைகளைக் குறிப்பிடுக.
4. பல்லவர்களின் தலைநகரத்தையும் கடற்கரை நகரத்தையும் குறிப்பிடுக.

---

#### ஈ. யாருடைய கூற்று?
1. “யானோ அரசன், யானே கள்வன்”.

# 4-ஆம் வகுப்பு சமூக அறிவியல் - முதல் பருவம்

## அலகு 2: ஐவகை நில அமைப்பு

---

### பாடநூல் மதிப்பீடு வினாக்கள்

#### அ. பட்டியலிடு
1. உங்கள் மாவட்டத்தில் உள்ள மலைகளையும் அவை அமைந்துள்ள ஊர்களையும் எழுதுக.
   - வ.எண் | மலைகள் | ஊர்கள்
2. உங்கள் பள்ளியைச் சுற்றியுள்ள மரங்களின் பெயர்களை எழுதுக.
   - வ.எண் | மரங்களின் பெயர்கள்

---

#### ஆ. கோடிட்ட இடங்களை நிரப்புக
1. பரந்த சமமான நிலப்பரப்பு _______ எனப்படுகிறது.
2. உலகின் மிகப்பழமையான நான்காவது பெரிய நீர்ப்பாசனவசதி கொண்ட நீர்த்தேக்கம் ____________.
3. கன்னியாகுமரி மாவட்டத்தில் அமைந்துள்ள காடுகள் ___________.
4. வயலும் வயல் சார்ந்த இடமும் ___________ ஆகும்.
5. ____________ இந்தியாவின் மிகப்பெரிய சதுப்புநிலக் காடு ஆகும்.
6. மெரினா கடற்கரை ____________ பகுதியில் அமைந்துள்ளது.

---

#### இ. பொருத்துக

##### i)
1. முருகன் - முல்லை
2. திருமால் - பாலை
3. இந்திரன் - குறிஞ்சி
4. வருணன் - மருதம்
5. கொற்றவை - நெய்தல்

##### ii)
1. கடவுள் - கிழங்கு அகழ்தல்
2. மலர் - குறவர், குறத்தியர்
3. மக்கள் - குறிஞ்சி மலர்
4. தொழில் - முருகன்

---

#### ஈ. குறுகிய விடையளிக்க
1. ஐவகை நிலங்களில் வாழ்ந்த மக்களின் பெயர்களை எழுதுக.
2. முல்லை நிலத்தின் நான்கு கருப்பொருட்களைப் பட்டியலிடுக.
3. செம்புலம் பற்றி நீ அறிவது யாது?
4. பாலை நிலம் எவ்வாறு உருவானது?
5. பாலை நிலத்தின் கருப்பொருள் யாது?

## அலகு 3: நகராட்சி மற்றும் மாநகராட்சி

---

### பாடநூல் மதிப்பீடு வினாக்கள்

#### அ. கோடிட்ட இடங்களை நிரப்புக
1. தமிழ்நாட்டின் மிகப்பழமையான மாநகராட்சி _____________ ஆகும்.
2. உள்ளாட்சியின் தந்தை என்று அழைக்கப்படுபவர் _____________.
3. _____________ ஆம் ஆண்டு பல்வந்த்ராய் மேத்தா குழு அறிக்கையின்படி இந்தியாவில் மூன்றடுக்கு பஞ்சாயத்து முறை அறிமுகப்படுத்தப்பட்டது.
4. நகராட்சியின் பணிக்காலம் _____________ ஆண்டுகள் ஆகும்.

---

#### ஆ. பொருத்துக
1. கிராமப்புற உள்ளாட்சி - 5,000க்கும் மேற்பட்ட மக்கள் தொகை
2. ரிப்பன் கட்டிடம் - நகரியம்
3. நெய்வேலி - கிராம ஊராட்சி
4. பேரூராட்சி - மாநகராட்சி
5. மேயர் - ரிப்பன் பிரபு

---

#### இ. காலி இடங்களை நிரப்புக

| வ.எண். | விவரம் | நகராட்சி | மாநகராட்சி |
| :---: | :--- | :--- | :--- |
| 1 | தலைவர் | நகராட்சியின் தந்தை | |
| 2 | எண்ணிக்கை | | 21 |
| 3 | பணிக்காலம் | | |
| 4 | அதிகாரிகள் | ஆணையர் | |
| 5 | வருவாய் | | தொழில் வரி |

---

#### ஈ. சுருக்கமாக விடையளிக்கவும்
1. மாநகராட்சியின் பணிகள் யாவை?
2. உள்ளாட்சியின் அமைப்பு பற்றி குறிப்பு வரைக?
3. நகராட்சியின் தலைவர் எவ்வாறு தேர்ந்தெடுக்கப்படுகிறார்?
4. தமிழ்நாட்டில் மாநகராட்சிகளின் எண்ணிக்கை யாது?
5. நகராட்சியின் வருவாய் ஆதாரங்கள் யாவை?
